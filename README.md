# Evora Beauty Website

A modern single-page beauty business website built with React, Vite, and CSS.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
```

## Docker

```bash
docker build -t beauty-website .
docker run -d -p 3000:3000 --name beauty-website beauty-website
```
